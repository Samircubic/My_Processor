# Стековый процессор

Учебный проект на C++17, осень 2024 года. Ассемблер переводит текстовые
команды в числовые коды. Виртуальная машина читает коды и выполняет команды
с помощью учебного динамического стека.

```sh
make
./assembler processor/data/example.asm /tmp/my-processor-program.txt
./machine /tmp/my-processor-program.txt
```

Пример складывает 30 и 12. Машина печатает `42`.

| Команда | Код | Действие |
| --- | --- | --- |
| `push N` | 1 | Положить целое число в стек |
| `pop` | 2 | Снять верхний элемент и напечатать его |
| `add` | 3 | Снять два элемента и положить в стек сумму |
| `htl` | 0 | Завершить выполнение |

`htl` — написание из исходного ассемблера. Корневая команда `make` собирает
два компонента этого сценария. Черновики дизассемблера и отдельной
арифметической демонстрации сохранены для истории работы.
