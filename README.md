# Стековый процессор

Учебный проект на C++17 из двух частей. Ассемблер превращает текстовую программу в числовые команды, а стековая машина их выполняет.

## Запуск

```sh
make
./assembler processor/data/example.asm program.txt
./machine program.txt
```

Файл `example.asm` кладёт в стек числа 30 и 12 командой `push`. Команда `add` заменяет их суммой, `pop` печатает `42`, а `htl` завершает программу.

Можно поменять числа в примере и заново прогнать обе команды. Промежуточный файл `program.txt` показывает, как выглядит программа после работы ассемблера.
