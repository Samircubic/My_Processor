# Стековый процессор

Учебный проект на C++17. Ассемблер переводит `push`, `pop`, `add` и `htl` в числовые команды, которые выполняет стековая машина.

```sh
make
./assembler processor/data/example.asm program.txt
./machine program.txt
```

Пример складывает 30 и 12 и печатает `42`. `htl` — команда остановки в исходном синтаксисе задания.
